## Reproduction commands

Run these commands from the repository root in PowerShell. The solution and `global.json` are intentionally under the allowed `src/host/` directory, so enter that directory before invoking `dotnet`:

```powershell
Push-Location .\src\host
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
dotnet --info
dotnet --list-sdks
dotnet restore .\MaggieVision.Host.sln --locked-mode
dotnet build .\MaggieVision.Host.sln --configuration Release --no-restore
dotnet test .\MaggieVision.Host.sln --configuration Release --no-build --logger 'console;verbosity=normal'
Pop-Location
```

Direct package versions are exact in both project files; `packages.lock.json` files record resolved transitive packages and content hashes. Restore used locked mode. No root build/SDK infrastructure or workflow was required.
